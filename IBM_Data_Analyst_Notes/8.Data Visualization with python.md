### Module 1 — Introduction to Data Visualization Tools

Data visualization is presenting complex data in a graphical form that is easy to understand. It is crucial when analyzing large volumes of data and making data-driven decisions.

**Why it matters (from the course dialogue — Samir’s answers):**

- Communicates complex insights to non-technical stakeholders; makes patterns, trends, and correlations easier to spot than in raw numbers
- Helps identify areas for improvement, track change over time, and make data-driven decisions with more confidence

> [!note]
> A stakeholder who says “a table of raw numbers is enough” still benefits from a chart: visualization does **not** auto-correct missing data, store data more efficiently, or replace summary statistics. It makes patterns, changes, and comparisons easier to spot quickly.

**Best practices when creating visuals**

- Select a plot type that matches the data and the question
- Choose colors and fonts that are easy to read
- Minimize clutter
- Three design points from the final exam: **Less is more effective; less is more attractive; less is more impactive.** Every feature should support the intended message without distraction.

**Data storytelling** is the art of creating a narrative around the data. Visualization is a core part of that narrative.

#### Types of plots (when to use which)

| Plot | What it shows |
|---|---|
| Line | Trends and changes over time (connected points) |
| Bar / bar graph | Compare categories or groups; length proportional to value |
| Scatter | Relationship between typically two variables (often dependent vs independent) |
| Box | Distribution via five measures: min, Q1, median, Q3, max (plus IQR and outliers) |
| Histogram | Frequency of a **numeric** dataset, partitioned into bins |
| Area | Cumulated totals using numbers or percentages; magnitude **and** proportion over a continuous axis (usually time). Similar to a line plot |
| Pie | Circular graphic divided into segments to show numerical proportions — **not** ideal for comparing categories |
| Density | Shape/spread of a single numeric variable (dialogue; used alongside histograms) |

> [!warning]
> Line plots can mislead if axis scales are not chosen to reflect the data accurately.

#### Matplotlib history and architecture

- Created by **John Hunter**, an American neurobiologist
- Initially developed as an **EEG/ECoG** visualization tool
- Designed to emulate **MATLAB-style** plotting while remaining an independent Python library — not a database tool, spreadsheet replacement, or browser-only dashboard library
- One of the most widely used Python visualization libraries; integrates in different environments
- Anatomy of a plot = the components that make up the visual (axes, labels, title, legend, etc.)

**Three main layers:** Backend · Artist · Scripting

Backend layer’s three built-in interface classes:

1. **FigureCanvas**
2. **Renderer**
3. **Event**

> [!tip]
> The **Artist layer** is the appropriate programming pattern when writing a web application server or UI application — that is where much of the heavy lifting happens.

**Two interfaces**

- **pyplot / scripting (implicit, state-based):** convenient for quick plots (`plt.plot`, `plt.title`, …)
- **Axes / object-oriented:** explicit `fig, ax = plt.subplots()` — better for reusable functions and several customized subplots

```python
fig, ax = plt.subplots()
ax.plot(years, totals)   # line of annual totals
```

**Jupyter / backends**

- Jupyter Notebook is an open-source web app for documents with live code, visualizations, and text
- Matplotlib has several backends. A magic function starts with `%matplotlib`
- `%matplotlib inline` generates plots **in the browser**. **Limitation:** you **cannot modify a figure after it is rendered** (cannot add title/labels after the fact)
- `%matplotlib notebook` also appears as a backend option in quizzes

> [!warning]
> If you edit the cell that defines `years` but rerun only the plotting cell, the chart still shows old x-values. Rerun the data-definition cell, then the plotting cell. Notebook output reflects executed-cell state.

### Module 2 — Basic and Specialized Visualization Tools

Create area plots, histograms, bar charts, pie charts, box plots, scatter plots, and bubble plots with Matplotlib / Pandas.

#### Area plots

- Also called area chart/graph
- Depict **cumulated totals** using **numbers** or **percentages** over time
- Display **magnitude and proportion** of multiple variables over a continuous axis (typically time)
- Similar to a **line** plot
- First step when creating one (final exam): import matplotlib as `mpl` and its scripting interface as `plt`

#### Histograms

- Frequency distribution of a **numeric** dataset (not alphabetical/demographic as the defining type)
- Partition the spread into **bins**, assign each point to a bin, count points per bin
- **Vertical** axis = frequency / number of data points in each bin
- First import step in the graded quiz: `import matplotlib as mpl` and scripting interface as `plt`

A **bar chart** is similar to a histogram in being used to compare values of a variable at a given point in time, but unlike a histogram the length of each bar is proportional to the value of the item it represents. A bar chart is also called a **bar graph**.

#### Pie charts

- Circular statistical graphic divided into segments to illustrate numerical proportions
- `explode` offsets slices from the center to highlight sections
- Course summary also says pie-chart creation involves importing Matplotlib to represent a large set of data over a period of time

#### Box plots

Five main measures: **Minimum, First quartile (Q1), Median, Third quartile (Q3), Maximum**.

Graded-quiz anatomy of a labeled box plot:

| Letter | Meaning |
|---|---|
| A | Median (middle line in the box) |
| B | Third quartile / Q3 (top of box) |
| C | First quartile / Q1 (bottom of box) |
| D | Interquartile range (box height) |
| E | Minimum (lower whisker) |
| F | Outliers (individual points) |

#### Scatter and bubble

- Scatter: typically two variables against each other — usually dependent vs independent — to see if a correlation exists
- Bubble: scatter with a third dimension encoded as point **size** (used in the final project with `Seasonality_Weight`)

#### Plotting with Pandas (`DataFrame.plot` / `Series.plot`)

| Plot | Purpose | Pandas API | Example |
|---|---|---|---|
| Line | Trends over time | `df.plot.line()` or `kind='line'` | `df.plot(x='year', y='sales', kind='line')` |
| Area | Filled series, relationship between them | `df.plot.area()` or `kind='area'` | `df.plot(kind='area')` |

#### Treemaps

Hierarchical data as **nested rectangles**: each branch is a rectangle tiled with smaller rectangles for sub-branches. Useful for large hierarchical datasets; space-efficient.

**Applications:** business analytics (sales by category/subcategory); finance (portfolios, sectors); IT/network (file systems, usage); bioinformatics (taxonomies, genomes); website analytics (pages sized by visits).

**Why they matter:** space efficiency; hierarchy + quantitative relationships; compare sizes across levels; color and size give quick pattern/outlier insight.

```python
import pandas as pd
import plotly.express as px

data = {
    'Category': ['Electronics', 'Electronics', 'Electronics',
                 'Furniture', 'Furniture', 'Furniture',
                 'Clothing', 'Clothing', 'Clothing'],
    'Subcategory': ['Laptops', 'Smartphones', 'Tablets',
                    'Chairs', 'Tables', 'Sofas',
                    'Men', 'Women', 'Kids'],
    'Sales': [120000, 80000, 30000, 50000, 40000, 20000, 70000, 90000, 40000]
}
df = pd.DataFrame(data)

fig = px.treemap(
    df,
    path=['Category', 'Subcategory'],  # hierarchy
    values='Sales',                    # rectangle size
    title='Sales Data Treemap'
)
fig.show()
```

Generic form: `path=['Category', 'Subcategory']`, `values='Value'`. Install: `pip install plotly pandas`.

#### Pivot charts

Dynamically summarize and explore large datasets. Used in business intelligence, finance, marketing, operations, and healthcare.

**Why they matter:** summarization; interactive filter/sort/drill-down; trend identification; faster interpretation than manual processing; presentation-ready reports.

**Idea:** treat one field as row index, others as columns, and an aggregated value (e.g. Item as index; Category and Subcategory as columns; Value aggregated).

```python
import pandas as pd
import matplotlib.pyplot as plt

data = pd.read_csv('your_dataset.csv')
pivot_table = data.pivot_table(
    values='ValueColumn',
    index='RowIndexColumn',
    columns='ColumnIndexColumn',
    aggfunc='sum'
)
pivot_table.plot(kind='bar')
plt.title('Pivot Chart Title')
plt.xlabel('X-axis Label')
plt.ylabel('Y-axis Label')
plt.show()
```

**Worked example — IT product sales by quarter** (dummy data, `np.random.seed(40)`):

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

num_quarters = 4
num_categories = 4
num_subcategories = 3
num_samples = num_quarters * num_categories * num_subcategories * 50

np.random.seed(40)

dates = np.repeat(['Q1', 'Q2', 'Q3', 'Q4'], 50 * num_categories * num_subcategories)
categories = np.tile(
    np.random.choice(['Laptops', 'Desktops', 'Peripherals', 'Software'], size=num_quarters * 50),
    num_categories * num_subcategories
)
subcategories = np.tile(
    np.random.choice(['Accessories', 'Components', 'Software Suites'], size=num_quarters * 50),
    num_categories * num_subcategories
)
sales_values = np.random.randint(1000, 5000, size=num_samples)

df = pd.DataFrame({
    'Date': dates,
    'Category': categories,
    'Subcategory': subcategories,
    'Sales': sales_values
})

pivot_table = df.pivot_table(
    index='Date',
    columns=['Category', 'Subcategory'],
    values='Sales',
    aggfunc=np.sum
)

pivot_table.plot(kind='bar', figsize=(14, 8))
plt.title('Sales Summary of IT Products by Category and Subcategory')
plt.xlabel('Quarters')
plt.ylabel('Total Sales')
plt.grid(False)
plt.legend(title=('Category', 'Subcategory'), bbox_to_anchor=(1.05, 1), loc='upper left')
plt.tight_layout()
plt.show()
```

Sample dummy rows look like: Date (Q1–Q4), Category (Peripherals / Software / Desktops / Laptops), Subcategory (Accessories / Components / Software Suites), Sales (integers ~1000–5000).

#### Folium — maps, markers, choropleths

Python library for interactive geospatial visualization. Data sources mentioned: GeoJSON, Pandas DataFrames, NumPy arrays.

```python
import folium

world_map = folium.Map()
canada = folium.Map(location=[56.130, -106.35], zoom_start=4)
```

- `location` = latitude and longitude of the **center**
- `zoom_start` = initial zoom (you can still zoom after render). Graded-quiz wording of the parameter: `zoom_start=parameter`
- **Default tiles:** Open Street Map — street view when zoomed in; country borders when zoomed all the way out
- **Stamen terrain:** hill shading and **natural vegetation colors**
- **Stamen toner:** also in the cheat sheet
- `tiles` parameter selects map style
- **Mapbox Bright** tileset displays the name of every country when used on a map

**Markers** represent specific locations / points of interest and show extra info when clicked (`popup`). You can display **multiple** markers. They can be created using a **feature group**. `folium.Marker()` takes location parameters.

Cheat-sheet marker examples (course sheet also used `556.130` in one marker line — inconsistent with Canada’s `[56.130, -106.35]` on `Map`):

```python
folium.Marker(location=[56.130, -106.35], tooltip='Marker', tiles='Stamen Toner').add_to(world_map)

    location=[56.130, -106.35],
    radius=1000,
    color='red',
    fill_opacity=0.5

```

**Choropleth** = a **thematic** map: areas shaded or patterned in proportion to a statistical variable.

# Course example
world_map.choropleth(
    geo_data=world_geo,

### Module 4 — Creating Dashboards with Plotly and Dash

Dashboards give a consolidated, understandable view of key data and metrics. They can provide **real-time visuals**, which makes moving parts of a business easier to understand and supports informed decisions.

**Web-based dashboarding tools** in Python (named in this module / exam): Dash (primary), Plotly; exam distractors for “static, animated, and interactive visualizations” included Flask, ipywidgets, and Bowtie — the correct library for that wording is **Matplotlib**. Data can be presented using different types of **dashboards**.

#### Plotly

Interactive, open-source plotting library supporting **over 40** unique chart types. Supported languages in the practice quiz: **Python and JavaScript** (the library cheat sheet also lists R).

Web-based Plotly Python figures can be:

- displayed in Jupyter Notebook
- saved to standalone HTML files
- served in pure-Python web apps using **Dash**

**Two sub-modules**

- **Plotly Graph Objects** — low-level interface to figures, traces, and layouts. Automatically generated hierarchy of classes. A Plotly graph contains a **JSON** object with a dictionary structure.
- **Plotly Express (`px`)** — **high-level** wrapper around Plotly. Recommended **starting point** for the most common figures (simple syntax). Uses graph objects internally.

```python
fig.update_layout()           # update title, axis labels, annotations
fig.add_trace(trace_object)   # add traces to an existing figure
```

**Plotly Express cheat sheet**

| Chart | Syntax | Example |
|---|---|---|
| Scatter | `px.scatter(dataframe, x=x_column, y=y_column)` | `px.scatter(df, x=age_array, y=income_array)` |
| Line | `px.line(x=x_column, y=y_column, 'title')` | `px.line(x=months_array, y=no_bicycle_sold_array)` |

#### Dash

Open-source user-interface Python library for **reactive, web-based** applications (enterprise-ready; first-class Plotly open-source tool). Python framework for building **web analytic applications**. It abstracts the technologies needed for GUIs.

**Two component libraries**

- **`dash_core_components` (`dcc`)** — higher-level interactive components generated with JavaScript, HTML, and CSS via React.js (`dcc.Input`, `dcc.Graph`, `dcc.Dropdown`, …)
- **`dash_html_components` (`html`)** — a component for every HTML tag (`html.Div`, `html.H1`, `html.P`, …)

```python
dcc.Input(value='Hello', type='text')
dcc.Graph(figure=fig)
html.Div(children=[html.H1('Hello Dash'), html.P('Welcome to Dash')])
dcc.Dropdown(
    options=[{'label': 'Option 1', 'value': '1'}, {'label': 'Option 2', 'value': '2'}],
    value='1'
)
```

**`html.Div`** creates a **container** for other components and organizes content — not primarily for the main title/styling, applying CSS globally, or loading external data.

#### Callbacks

A **callback** is a Python function **automatically called by Dash** whenever an input component’s property changes. The **`@app.callback` decorator** tells Dash to call it on input change, then the output component in the layout updates.

- Takes **Input** and **Output** components as **parameters**
- **Output** sets the callback result onto a component id
- **Input** is the parameter needed to decorate the callback (final exam)

Correct decorator form:

```python
@app.callback(
    Output(component_id='bar-plot', component_property='figure'),
    Input(component_id='input-yr', component_property='value')
)
```

(Parentheses on `Output`/`Input`, not `{}` or `[]`.)

A callback function is described in the graded quiz as a **decorator** (the wrapped function is called when input changes, then output children update).

## Definitions

| Term | Definition |
|---|---|
| Data visualization | Presenting data as charts, graphs, or maps so people can understand and analyze it more easily |
| Data storytelling | Creating a narrative around the data; visualization is a major part of that narrative |
| Line plot | Series of data points connected by straight line segments; shows trends/changes over time |
| Area plot / area chart | Filled plot showing magnitude and proportion of multiple variables over a continuous axis (often time); cumulated totals as numbers or percentages |
| Histogram | Frequency distribution of a numeric dataset, using bins |
| Bar chart / bar graph | Plot whose bar length is proportional to the value of the item; compares categories or values at a point in time |
| Pie chart | Circular statistical graphic divided into segments to illustrate numerical proportions |
| Box plot | Distribution shown with five measures: minimum, Q1, median, Q3, maximum (plus IQR and outliers) |
| Scatter plot | Values of typically two variables plotted against each other (often dependent vs independent) |
| Bubble plot | Scatter plot with point size encoding a third variable |
| Treemap | Hierarchical data as nested rectangles; size (and often color) encode quantity |
| Pivot chart | Chart of a pivot table: dynamic summarization with rows, columns, and aggregated values |
| Waffle chart | Categorical data as a grid of equal-sized square tiles/cells |
| Word cloud | Visual of word importance/frequency in text |
| Choropleth map | Thematic map with areas shaded/patterned in proportion to a statistical variable |
| GeoJSON | File of geospatial features (e.g. country borders) required by Folium choropleths |
| Backend / Artist / Scripting | Matplotlib’s three architecture layers |
| FigureCanvas, Renderer, Event | Backend layer’s three built-in interface classes |
| pyplot | Matplotlib scripting interface for quick create/customize |
| Object-oriented / Axes interface | Explicit figures and axes (`plt.subplots`) for reusable, multi-plot code |
| Plotly Express | High-level wrapper for common Plotly figures; uses graph objects internally |
| Plotly Graph Objects | Low-level hierarchy of figure/trace/layout classes; figures are JSON/dict-structured |
| Dash | Open-source Python UI library / framework for reactive web analytic apps |
| dash_core_components | Higher-level interactive Dash components (JS/HTML/CSS via React) |
| dash_html_components | Dash wrapper for HTML tags |
| Callback | Python function Dash calls automatically when an input component property changes; decorated with `@app.callback` |
| Seasonality_Weight | Final-project field: `>1` higher-than-average seasonal sales, `<1` slowdown, `~1` neutral |

## Tips & Best Practices

- Less is more effective, more attractive, and more impactive — drop decorative noise
- Match plot type to the question: line for time, bar for categories, scatter for two numerics, histogram/density for one numeric distribution, pie for simple proportions
- Prefer the **object-oriented** Matplotlib interface when writing reusable functions with several customized subplots
- Always inspect structure (`info`, `head`), then clean/shape, then plot
- Start Plotly work with **Plotly Express**; drop to graph objects when you need traces/layout control (`add_trace`, `update_layout`)
- For Dash interactivity, wire `Input`/`Output` in `@app.callback` and keep layout ids in sync
- On maps, set `location` (center) and `zoom_start`, then add markers or a choropleth keyed to GeoJSON properties
- Verify spikes and outliers against the raw values before concluding

## Common Mistakes

> [!warning]
> Using `type='bar'` in `DataFrame.plot()` — the parameter is `kind`, not `type`. (`question.plot(type='bar', rot=90)` is false.)

> [!warning]
> Expecting to add a title or axis labels after a figure is drawn with `%matplotlib inline`. The inline backend cannot modify a figure once it is rendered.

> [!warning]
> Rerunning only the plotting cell in Jupyter after changing `years` (or any source data). Re-execute the definition cell first.

> [!warning]
> Using pie plots or scatter plots to compare different categories or groups. Bars (and similar) are the comparison tools; pie shows proportions, scatter shows two-variable relationships.

> [!warning]
> Choosing line-plot axis scales that distort the data. Poor scales make trends look stronger or weaker than they are.

> [!warning]
> Treating a sharp one-year spike on an immigration (or sales) line as proof of long-term growth, or deleting it to “smooth” the chart. Investigate the underlying values first.

> [!warning]
> Putting `Vehicle_Type` on the x-axis for the final-project grouped bar of sales in recession vs stable periods. Required form: `sns.barplot(data=df, x='Recession', y='Automobile_Sales', hue='Vehicle_Type')`. (Samir’s Q2: 0/2.)

> Submitting a Part 1 notebook with placeholder bar-chart code, a missing yearly-mean line chart, or a missing seasonality bubble plot. Grader wanted: `groupby(Year).mean()` line; complete `sns.barplot`; non-recession scatter with size = `Seasonality_Weight`. (Notebook 9/18.)

## Interview Questions

### Beginner

1. **Q: What is data visualization, and why add a chart when a table already exists?**
   A: It is presenting data as charts, graphs, or maps so people can understand it more easily. A good visual makes patterns, changes, and comparisons easier to spot quickly than raw numbers; it does not replace cleaning, storage, or summary statistics.

2. **Q: Who created Matplotlib, and what was it originally for?**
   A: John Hunter, an American neurobiologist. It began as an EEG/ECoG visualization tool and was designed to emulate MATLAB-style plotting as an independent Python library.

3. **Q: What are Matplotlib’s three main layers, and what are the backend’s three interface classes?**
   A: Layers: Backend, Artist, and Scripting. Backend classes: FigureCanvas, Renderer, and Event.

4. **Q: When would you use a line plot vs a histogram vs a scatter plot?**
   A: Line for trends over time; histogram (or density) for the distribution of one numeric variable (bins + frequencies); scatter for the relationship between two numeric variables.

5. **Q: What is a box plot’s five-number summary?**
   A: Minimum, first quartile, median, third quartile, and maximum. The box height is the IQR; points beyond the whiskers are outliers.

### Intermediate

1. **Q: pyplot vs the object-oriented Matplotlib interface — when do you choose each?**
   A: Pyplot is the convenient scripting layer for quick plots. For a reusable function that builds several customized subplots, use the Axes/object-oriented interface (`fig, ax = plt.subplots()`) so figures and axes are explicit.

2. **Q: How do you turn a country×year immigration table into a line of one country’s trend?**
   A: Inspect with `info()`/`head()`, clean/select, then use a one-dimensional series of yearly values indexed by year, e.g. `immigration_df.plot(x="Year", y="India", kind="line")`.

3. **Q: How do you create a Folium map of Canada and a choropleth of immigration totals?**
   A: Center with `folium.Map(location=[56.130, -106.35], zoom_start=4)`. For a choropleth, supply a GeoJSON of borders plus data columns such as `['Country', 'Total']` and `key_on='feature.properties.name'`. Default tiles are Open Street Map; Stamen terrain shows vegetation colors.

4. **Q: What is the difference between Plotly Express and Plotly Graph Objects?**
   A: Express is a high-level wrapper and the recommended starting point for common figures; it uses graph objects internally. Graph objects are the low-level figure/trace/layout API (JSON/dict structure) with `add_trace` and `update_layout`.

5. **Q: How does a Dash callback connect a dropdown to a graph?**
   A: Decorate a function with `@app.callback(Output(component_id=..., component_property='figure'), Input(component_id=..., component_property='value'))`. Dash calls it when the input property changes; Output writes the returned figure onto the component id.

### Advanced

1. **Q: Which Matplotlib layer would you use when embedding plots in a web application server or UI, and why?**
   A: The Artist layer — the course identifies it as the appropriate paradigm for that setting, where much of the heavy lifting happens (as opposed to the pyplot scripting layer).

2. **Q: Design the XYZAutomotives recession dashboard: what does each report mode show, and how do the dropdowns behave?**
   A: Recession Period Statistics vs Yearly Statistics. The year dropdown is disabled for recession reports and enabled for yearly reports so a specific year can be chosen. Recession graphs include vehicle-type sales, GDP, seasonality bubbles, price–sales scatter, and ad-spend pies; a pie is the component for advertising expenditure by vehicle type.

3. **Q: How do you compare average automobile sales by vehicle type in recession vs non-recession, and what did the project chart show?**
   A: `sns.barplot(data=df, x='Recession', y='Automobile_Sales', hue='Vehicle_Type')` — Recession on x, type as hue. Observed: sales higher in non-recession for all types; executive and sports lowest in both conditions; SuperMiniCar outsold ExecutiveCar in recession.

4. **Q: How do you show seasonality’s impact on automobile sales as a bubble plot?**
   A: Filter to non-recession years (per the Part 1 grader), then a Matplotlib scatter with bubble size mapped to `Seasonality_Weight`, titled `'Seasonality impact on Automobile Sales'`. Seasonality_Weight `>1` means higher-than-average seasonal sales, `<1` a slowdown, `~1` neutral.

5. **Q: Contrast waffle charts, treemaps, and choropleths — what data shape does each expect?**
   A: Waffle: categorical parts-of-whole as equal square tiles (PyWaffle). Treemap: hierarchy via `px.treemap` `path` + `values` (nested rectangles). Choropleth: regional statistics joined to GeoJSON geometries in Folium, shaded in proportion to the measure.
